# Lunar Rescue

Taito's Lunar Rescue from 1979. Same 8080 board as Space Invaders, with a color PROM and the Taito PV sound wiring. Upright cabinet.

## Specs

- CPU: Intel 8080 at 1.9968 MHz
- Video: the Space Invaders bitmap, colored from a 1K PROM, plus the red-screen latch
- Sound: Taito PV discrete analog plus a TI SN76477
- Controls: left, right, fire, and the coin door
