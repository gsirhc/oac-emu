# Asteroids

Atari's Asteroids board from 1979.

## Specs

- CPU: MOS 6502 at 1.512 MHz (12.096 MHz / 8)
- Video: Atari Digital Vector Generator, on a 4:3 vector monitor
- Sound: discrete. Thump, saucers, fire, explosion, thrust, and the extra-life tone.
- Controls: 5 buttons (rotate, thrust, fire, hyperspace) and the coin door
