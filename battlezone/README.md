# Battlezone

Atari's Battlezone board from 1980.

## Specs

- CPU: MOS 6502 at 1.512 MHz (12.096 MHz / 8)
- Video: Atari Analog Vector Generator, with the window and intensity circuits
- Math Box: two Am2901 bit-slice ALUs and the Atari sequencer
- Sound: Atari POKEY plus the discrete explosion and motor sounds
- Controls: two sticks (left and right tread), fire, and the coin door
