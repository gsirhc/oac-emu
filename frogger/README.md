# Frogger

Konami's Frogger board from 1981, the Sega-licensed US upright.

## Specs

- CPU: two Zilog Z80s. The game CPU is 3.072 MHz. The sound CPU is 1.789772 MHz.
- Video: Galaxian-family tilemap and sprites, upright, 60.606 Hz
- Sound: one GI AY-3-8910
- I/O: two Intel 8255s
- Controls: 4-way joystick and the coin door
