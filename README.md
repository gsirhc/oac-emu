# oac-emu

Browser emulators of vintage machines, built from primary sources: schematics,
datasheets, period manuals and original ROM listings. Each machine is C++
compiled to WebAssembly, runs at its real clock rate, and ships with a
GoogleTest suite and a Playwright suite. The site is served from GitHub Pages
at <https://gsirhc.github.io/oac-emu/>.

## Machines

- [`altair8800/`](altair8800/) MITS Altair 8800 (Intel 8080), with front panel, paper tape, cassette and floppy.
- [`assembler6502/`](assembler6502/) hand-built W65C02S single-board computer. Boots Wozmon, then a resident editor and assembler. Firmware source is in [`assembler6502/firmware/`](assembler6502/firmware/).
- [`ibmpc-at/`](ibmpc-at/) IBM PC/AT (80286, EGA, WD1003), booting FreeDOS.
- [`pc486/`](pc486/) 486 DX2-66 gaming PC (VGA, VBE, Sound Blaster 16).
- Arcade boards: [`pacman/`](pacman/), [`frogger/`](frogger/), [`scramble/`](scramble/), [`galaxian/`](galaxian/), [`galaga/`](galaga/), [`asteroids/`](asteroids/), [`centipede/`](centipede/), [`missile/`](missile/), [`invaders/`](invaders/), [`lunarrescue/`](lunarrescue/), [`battlezone/`](battlezone/). Each ships a from-scratch self-test ROM. A real ROM set is opt-in and stays in the browser.

Every machine has a `*_REVIEW.md` with its hardware findings and citations.

## Layout

- `index.html`, `super_secret.html`, `about.html`, `news_info.html`, `arcade/`: the landing page, the full catalog (deployed, not linked), the about page, the news page and the arcade hub. Computer cards use screenshots of this project's own rendered hardware; arcade cards are generated by [`shared/marquee.py`](shared/marquee.py) (see [`assets/README.md`](assets/README.md)).
- `<machine>/`: the C++ core and its `tests/` (GoogleTest). `<machine>/web/` is the front end and its Playwright suite.
- [`shared/`](shared/): front-end code every page uses (theme system, page bar, footer, fullscreen and focus hint), plus the shared CPU cores and chips (`shared/cpu/`, `shared/pc/`, `shared/galaxian/`, `shared/atari/`, `shared/namco/`, `shared/mw8080/`). Each machine's `web/Makefile` copies the front-end files into its own `web/shared/` (git-ignored), because only `web/` is staged.

## Build and test

Per machine:

```sh
make -C altair8800 test-smoke          # native smoke (what deploy CI runs)
make -C altair8800 check               # full native suite (nightly)
make -C altair8800/web                 # wasm (needs emscripten)
make -C altair8800/web test-smoke      # Playwright smoke
make -C altair8800/web test            # full Playwright suite
```

The same targets exist for every machine. The 6502 Assembler ROM is built from
`assembler6502/firmware/` with cc65: `make -C assembler6502 rom check`. The IBM
PC/AT and 486 build a FreeDOS hard disk image the first time (slow, cached
afterward). See each machine's `*_REVIEW.md` for details.

Deploy CI (`.github/workflows/deploy-emulator.yml`) runs smoke only. The full
suites run nightly (`.github/workflows/nightly-full.yml`).

## Site and preview

`make site` builds `_site/`: the root pages, `assets/`, a few shared files, and
each machine's `web/` (its `STAGE` list) at `/<machine>/`. `check_site.py`
fails the build if a source or tooling file gets in, or if a page, fetch,
worker or manifest refers to a file that wasn't staged.

```sh
make preview       # build everything, serve https://0.0.0.0:8000/ in the foreground
make preview-bg    # detached; stop with make preview-stop
make watch         # preview, restaging and live-reloading on edits
MACHINE=pc486 make watch   # wasm rebuilds only for that machine
make preview-install       # launchd agent that keeps :8000 up
```

A bare `python3 -m http.server` won't work. Each emulator lives at
`<machine>/web/` in source and at `/<machine>/` in the staged site.

## Lint

`make lint` runs ESLint, HTMLHint, tsc, cppcheck, actionlint, and the checks in
`check_site.py` and `check_emulator_refs.py`. JS deps install with `npm ci`
(the target does it when `node_modules/` is missing). cppcheck needs gtest
headers (`brew install cppcheck googletest`, or `apt install cppcheck
libgtest-dev`).

## Adding a machine

Create `<machine>/` with its core, `tests/` and `web/`, then wire it in: a
`.machine-card` in `index.html` (computers) or `arcade/index.html` (cabinets),
`MACHINES` and `_stage` in the root `Makefile`, `watch_site.py`, the CI jobs,
`.gitignore`, `eslint.config.js`, `lint-cpp.sh` and `package.json`. `CLAUDE.md`
has the full checklist.
