# Pac-Man

Midway's Pac-Man board from 1980. Ms. Pac-Man is the same board with the GCC aux board.

## Specs

- CPU: Zilog Z80 at 3.072 MHz
- Video: Namco tilemap and 16x16 sprites, upright
- Sound: Namco wavetable generator
- Controls: 4-way joystick and the coin door
- RAM: the board's work RAM, video RAM, and color RAM
