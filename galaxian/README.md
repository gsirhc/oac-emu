# Galaxian

Namco's Galaxian board from 1979, the Midway set.

## Specs

- CPU: Zilog Z80 at 3.072 MHz
- Video: Galaxian tilemap and sprites, upright, 60.606 Hz
- Sound: discrete analog, clocked at 1.536 MHz
- Controls: 2-way joystick, fire, and the coin door
