# Space Invaders

Midway's Space Invaders board from 1978, PCB 739. Upright only. The cocktail board isn't modelled.

## Specs

- CPU: Intel 8080 at 1.9968 MHz
- Video: 1-bit bitmap, 256x224, with the Midway shifter. About 59.54 Hz.
- Sound: discrete analog plus a TI SN76477
- Controls: left, right, fire, and the coin door
