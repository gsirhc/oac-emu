# Missile Command

Atari's Missile Command board from 1980.

## Specs

- CPU: MOS 6502 at 1.25 MHz, half that over the city band. The frame averages 1,171,875 Hz.
- Video: 256x231 raster, 320 clocks by 256 lines, about 61 Hz
- Sound: Atari POKEY, into the Regulator/Audio II amp
- Controls: trackball, fire, and the coin door
