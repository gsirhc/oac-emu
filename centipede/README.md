# Centipede

Atari's Centipede board from 1981.

## Specs

- CPU: MOS 6502 at 1.512 MHz (12.096 MHz / 8)
- Video: playfield tiles and motion objects, color from an 82S25 RAM
- Sound: Atari POKEY
- Controls: trackball, fire, and the coin door
- High scores: the board's ER2055 EAROM
